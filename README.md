# AquaTrace

**Track the problem. Find the next step.**

AquaTrace is a community-focused civic technology project designed to improve access to water-service information in South Africa. It aims to help residents report water outages, discover alternative water points, and follow incident updates in one accessible platform.

## The problem

When water services are disrupted, residents may struggle to find reliable information about outages, service updates, and alternative water sources. Information can be fragmented, delayed, or difficult to verify.

AquaTrace explores how better reporting, verification, and information sharing could help communities respond to disruptions.

## Planned features

- Submit and view water outage reports.
- Track incident statuses and updates.
- Search and filter alternative water points.

- Distinguish verified information from unverified community reports.
- Provide an operator interface for reviewing reports and updating incident statuses.
- Present basic insights into recurring reports and service disruptions.

## Getting started

Requirements: Node.js and npm.

1. Clone the repository.
2. Install dependencies with `npm install`.
3. Start the development server with `npm run dev`.
4. Open the local address displayed in your terminal.

## Quality checks

- `npm run lint` — checks code quality.
- `npm run build` — checks TypeScript and builds the production application.

## Current status

The initial development environment has been created and the lint and production build checks have passed. Application features are still under development.

Any demonstration data used during development will be identified as sample data unless independently verified.

## Scope and limitations

AquaTrace is an information and coordination concept. It does not repair water infrastructure, guarantee the availability of water at alternative points, or represent an official municipal service. The accuracy of community reports and alternative water-point information will depend on verification and timely updates.
